# Diagrams

## Architecture Diagrams

All architecture diagrams are embedded in the workshop documents and the prototype application. Source formats:

- **System Context Diagram** (Workshop 1) — Stakeholder information flows
- **Node Relationship Graph** (Workshop 1) — Full system component graph
- **Layered Architecture** (Workshop 2) — Five-layer microservices decomposition
- **Process Flow Diagram** (Workshop 2) — Incident submission to alert dispatch
- **Refined Architecture** (Workshop 3) — Multi-AZ API gateway, RabbitMQ event bus, primary–standby replication
- **Quality Pipeline** (Workshop 3) — CI/CD quality gate sequence
- **Risk Heat Map** (Workshop 3) — 3×3 probability–impact matrix
